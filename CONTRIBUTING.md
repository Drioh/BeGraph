# Contributing to BeGraph

All kind of contributions is well accepted: [bug reporting](https://github.com/Drioh/BeGraph/issues), documentation improvement and refactoring, or pull request submitting.

> ***Remember:*** BeGraph is my Master's Degree thesis project. I am the only developer, and will continue to work on the project even after the first release out of pure passion, I am under no obligation to continue working at it.

### Submitting a pull request

* [Fork](https://github.com/Drioh/BeGraph/issues) and clone the repository ([GitHub Desktop](https://desktop.github.com/) makes this easy).
* Create a new branch.
* Make your changes.
* Push to your fork and [submit a pull request](https://github.com/Drioh/BeGraph/compare).
* Wait for your pull request to be reviewed.

If you're unfamiliar with how pull requests work, you can read [GitHub's documentation on the matter](https://help.github.com/articles/using-pull-requests/).

A few things to increase the likelihood of your pull request being accepted:

* Update the documentation of anything affected by your change.
* Keep your change as focused as possible. If there are multiple changes you would like to make that are not dependent upon each other, consider submitting them as separate pull requests.
* Make sure your pull request is in a merge-able state (GitHub will tell you if there will be merge conflicts).
